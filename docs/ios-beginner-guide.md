# 计划本：小白使用说明

适合你的 iPhone 14 Pro。先完成一次安装，以后点桌面的「计划本」就能用。

**你已装好 SideStore，直接做下面「第三步：安装计划本」。** 手机保持 Wi-Fi 和 LocalDevVPN 已连接。首次安装 SideStore 的步骤保留在这里，日后需要时再看。

## 1．先装到手机上

### 第一步：准备三个工具

| 在哪里 | 装什么 | 它是做什么的 |
|---|---|---|
| Windows 电脑 | iTunes、iloader | 让电脑识别手机，并首次安装 SideStore |
| iPhone | LocalDevVPN | 安装和续签时需要的本地连接工具 |

- **电脑**： 打开 [SideStore 官方准备页面](https://docs.sidestore.io/docs/installation/prerequisites)，选「Windows」，依次下载并安装 iTunes、iloader。安装器通常在电脑的「下载」文件夹中。
- **手机**： 打开 [LocalDevVPN 的 App Store 页面](https://apps.apple.com/app/localdevvpn/id6755608044)，点「获取」。打开它，点「Connect」；如提示添加 VPN 配置，按手机提示授权。

### 第二步：安装 SideStore（安装和续签的工具）

1. 保持手机用数据线连接电脑，并解锁。
2. 电脑打开 **iloader**，自行登录 Apple 账户，选择你的 iPhone。
3. 点 **Install SideStore (Stable)**，等安装结束。
4. 手机进入 **设置 → 通用 → VPN 与设备管理 → 你的开发者账户**，按提示信任、允许并重启。
5. 手机进入 **设置 → 隐私与安全性 → 开发者模式**，按提示开启并重启。如果暂时没看到这一项，先确认上一步已安装完成。
6. 手机连接 Wi-Fi，打开 LocalDevVPN 并连接，再打开 **SideStore**，登录刚才同一个 Apple 账户。
7. 在 **My Apps（我的应用）** 里，先点 SideStore 旁边的剩余天数刷新一次。成功后再装计划本。

登录密码、验证码和手机解锁密码由你自己输入，不用发给我。首次安装以 [SideStore 官方步骤](https://docs.sidestore.io/docs/installation/install)为准；iOS 27.0 还需要在你的手机实际验证。

### 第三步：安装计划本

1. 在手机浏览器打开 [计划本安装包下载页](https://github.com/DPclaude/ios/actions/runs/36522015078)，需要时登录 GitHub。
2. 找到页面下方 **Artifacts**，点 **Planner-native-19** 下载。
3. 打开 iPhone 的 **「文件」→「下载项」**。点下载的 ZIP 压缩包解压，在解压后的文件夹中找到 **Planner-unsigned.ipa**；找不到就用「文件」搜索这个名称。
4. 保持 Wi-Fi 和 LocalDevVPN 已连接。在 SideStore 的 **My Apps** 中，使用添加本地应用的入口（通常是「＋」），选择这个 **.ipa** 文件，等待安装。
5. 回到手机桌面，点 **「计划本」**。能看到「添加计划」按钮，就可以开始使用了。

**修复版说明**： 构建 19 已将签名名称改为英文 Planner，用于处理 `appIdName` 拒绝「计划本」的报错。SideStore 中可能显示 **Planner**，中文系统桌面名称仍配置为「计划本」。请重新下载这个版本，别选之前的旧 IPA；不用重装 SideStore。手机安装结果仍需实际重试确认。

**IPA 就是安装包。不要选 ZIP，也不需要打开测试报告文件。** 直接点 IPA 文件不会完成安装，需要交给 SideStore。

下载归档保留 7 天；若链接失效，把这件事告诉我，我可以重新生成。当前手机安装尚未完成。

## 2．每天使用：先学这三个操作

**写一件事**： 点底部「添加计划」→ 输入内容，例如「晚上散步 20 分钟」→ 点右上角「保存」。

**做完打勾**： 点计划左边的圆圈。计划会移到「已完成」；再点一次圆圈，可以改回未完成。

**修改内容**： 点计划的文字 → 修改 → 点「保存」。内容会自动保存在手机上；页面下方显示「所有更改已保存」就表示保存成功。

## 3．其他常用操作

| 你想做什么 | 怎么点 |
|---|---|
| 看明天或昨天 | 点日期旁的左右箭头；也可以点上面一周中的某一天 |
| 跳到某个日期 | 点中间的日期 → 选日期 →「完成」；点左上角「今天」回到今天 |
| 分成工作、私事、学习 | 添加或编辑计划时选「分类」；首页点对应分类筛选，点「全部」恢复显示 |
| 每天做同一件事 | 添加时打开「每天重复」；已有普通计划可点文字 →「改为每天重复」 |
| 连着添加多件事 | 添加时打开「保存后继续添加」。保存一件后继续写；最后一件保存前关掉这个开关 |
| 把计划放到明天／最上面 | 点计划文字 →「移到下一天」或「置顶」 |
| 删除一条计划 | 点计划文字 →「删除计划」；误删后，立即点底部「撤销」（7 秒内） |
| 写当天的小记 | 在「当天备忘」里直接输入，自动保存 |

**小提醒**： 普通未完成计划会在跨日刷新时顺延到今天；已完成的历史计划保留在原日期。每日重复计划每天分别打勾；修改其内容会影响整条重复规则，删除规则也会移除各日期的相关记录。

日常记计划可以离线用。当前版本把数据保存在这台手机上，没有自动跨设备同步。

## 4．把旧计划搬过来、备份数据

**第一次搬家**： 旧网页版导出 JSON 备份 → 存进手机「文件」→ 新计划本右上角齿轮 →「导入旧版备份」→ 选 JSON → 核对数量 →「确认覆盖并导入」。

导入会替换新 App 里的现有内容，所以最好在开始正式使用前导入。导入后对照检查几个日期，确认旧计划和备忘都在。

**平时备份**： 齿轮 →「导出备份」→ 保存到「文件」里的 iCloud Drive 或其他安全位置。建议每周一次；卸载或换手机前也做一次。

导入选错文件时，可以在设置点「恢复导入前的副本」。恢复会覆盖导入后新增的内容，先导出当前备份。**卸载 App 会删除手机上的计划和恢复副本。**

## 5．续签：让 App 过几天还能打开

免费安装的有效期通常是 **7 天**。「续签／刷新」就是延长有效期；不需要每天重装计划本。SideStore 提供后台刷新，但能否自动成功要在你的手机上验证。[官方说明](https://docs.sidestore.io/docs/faq)

**先验证一次手动续签**：

1. 手机连接 Wi-Fi，打开 LocalDevVPN 并连接。
2. 打开 SideStore → **My Apps**，分别点 SideStore 和计划本旁边的剩余天数，等刷新结束。
3. 确认有效期延长，再打开计划本，检查原来的内容还在。

**再设置自动刷新**：

- 在手机「设置 → 通用 → 后台 App 刷新」允许 SideStore 刷新。
- 如果当前 SideStore 在「快捷指令」中提供刷新动作，可建一条每天执行的个人自动化：先连接 LocalDevVPN，再刷新 SideStore 和计划本，选择「立即运行」。动作名称以你安装的版本为准；找不到时不要随便选别的动作。
- 先手动运行一次自动化，再观察一次真正的定时执行。成功后才算自动续签设置完成。

**现在还没替你启用自动续签。** 计划本安装成功后，我可以根据你的实际版本继续协助设置。自动刷新失败时，先按上面的步骤手动刷新，不要先卸载 App。

## 6．遇到问题，先看这里

| 遇到的情况 | 先做什么 |
|---|---|
| 电脑找不到 iPhone | 解锁手机、检查数据线、点「信任」；确认 iTunes 驱动安装完成 |
| 提示不受信任的开发者 | 回到「设置 → 通用 → VPN 与设备管理」检查对应账户的信任状态 |
| 报错 `appIdName`，并包含「计划本」 | 重新下载上面的构建 19，解压后在 SideStore 选择新 IPA；不要再次选择旧包 |
| 下载后不知道选哪个文件 | 只找 **Planner-unsigned.ipa**；ZIP 先解压 |
| 几天后打不开计划本 | 先检查 SideStore 的剩余天数，连接 Wi-Fi 和 LocalDevVPN 后刷新 |
| 提示「尚未保存」 | 点「重试保存」；若仍失败，去设置导出备份，先别卸载或强制退出 |
| 页面按钮与说明不一样／安装报错 | 把报错文字或截图发给我；遮住账户、验证码等私人信息 |
