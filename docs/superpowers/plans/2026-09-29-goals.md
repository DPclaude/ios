# Long-term goals and widget completion implementation plan

> **For agentic workers:** Use superpowers:executing-plans inline; one final independent review.

**Goal:** Deadline-based goals with dated stages and a single final widget completion update.
**Architecture:** Goal metadata plus existing canonical PlannerTask stages. Batch widget publication in the existing main-actor single writer; WidgetKit supplies the completion reload.
**Tech Stack:** Swift 6, SwiftUI, WidgetKit, AppIntents, XCTest, GitHub Actions macOS.
**Spec:** docs/superpowers/specs/2026-09-29-long-term-goals-design.md

## Global constraints
- Preserve bundle IDs, signing names, AppGroup and SideStore install/update paths.
- iOS 17 minimum; no new dependencies or private APIs.
- Preserve old user data; build and verify cloud-side because no local Xcode.

## Review focus
- Editing stages after rollover must preserve deadline unless deliberately edited.
- Stale editor cannot overwrite intervening stage completion or resurrect a deleted goal.
- Delete/undo stage retains goal association; deleting a goal invalidates that undo safely.
- Failed disk/share writes cannot publish completion success or silently lose reminders.
- Concurrent widget interactions/UI saves must drain latest revision without publishing old cold-load state.
