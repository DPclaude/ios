# 新版桌面组件与更新说明

适用原生版本 1.4.1。[打开最新版下载页](https://github.com/DPclaude/ios/releases/latest)。

## 点下后立刻看到反馈

点组件里的计划后，圆圈先变成绿色勾选，文字划线，显示「正在完成」；后台保存结束再归到下方。提示期间不用重复点。若保存失败，组件恢复真实状态并出现重试入口。系统调度仍可能影响归类速度，这个反馈用于明确告诉你点按已被接收。

## 长期目标：分阶段完成

1. 打开计划本，点首页的「长期目标」→ 右上角「新增目标」。
2. 写目标，例如「完成一本书」，选择目标截止日期。
3. 写第一个阶段，例如「读完前五章」，选择这个阶段的截止日期。
4. 点「添加阶段」继续拆分，想分几步就添加几个。每个阶段的日期不能晚于总截止日期。
5. 点「保存」。目标详情会显示已完成几个阶段。

阶段到期会进入当天计划和组件。点圆圈完成后，目标进度自动同步；也可以在目标详情提前完成。逾期阶段会顺延到今天，原定截止日期仍保留。需要提醒时，在对应日期的计划列表点阶段文字，打开「提醒我」。

修改阶段和截止日期：进入目标 →「编辑」。已完成记录会保留。误点完成：在目标详情再点一次勾。删除整个目标会同时删除它的阶段，请先看清确认提示。

## 第一次换到新版

1. 在旧计划本设置里导出一份备份。
2. 打开新版本下载页，下载 Planner.ipa（不需要 ZIP 解压）。
3. 在 SideStore 的 My Apps 中选择这个 IPA，沿用原来的 Apple 账户覆盖安装。
4. 如果提示是否移除扩展，请选择保留小组件扩展。安装后先打开计划本一次，检查原来的计划还在。

不要先卸载旧 App。组件需要单独的 App ID；若 SideStore 提示 App ID 数量暂时达到上限，保留旧版本和数据，等额度恢复后再试。

## 添加桌面大组件

1. 长按手机桌面空白处，点编辑／添加小组件。
2. 搜索「计划本」，选大号，点添加小组件。
3. 将组件拖到你希望的桌面页面；可以再放一个中号组件。
4. 点计划旁的小圆圈，直接在桌面勾选完成；完成项保留在下方。点组件空白处，直接新增今天的计划。

iPhone 桌面组件尺寸由 iOS 决定，不能变成无边框的整页。中号最多显示 2 项，大号最多 5 项；有已完成计划时，为下方完成分组留出位置，刚完成的计划优先显示在下方，完整列表在 App 内。新版合并了重复刷新，并取消行淡入淡出；点击后在保存完成时更新分组，具体时间仍由 iOS 调度。误点后打开 App，在「已完成」里点勾恢复。组件空白时，先打开计划本，去设置查看同步提示。

## 排序和重要计划

1. App 首页右上角点「排序」。
2. 按住计划右侧的三横线把手，拖到希望的位置，再点「完成排序」。待完成顺序同步到组件；组件下方优先展示最近完成的计划，App 内已完成列表仍可单独排序。
3. 新增或编辑时打开「重要计划」，文字会变红；已完成后变灰。每日计划的顺序和重要标记跟随整条重复规则。

分类只显示工作、私事、学习；可以不选，或再次点选中的分类取消。原来默认分类里的任务仍在「全部」中。

## 给每条计划设置提醒

1. 打开计划本，点「＋」添加计划，或者点已有计划文字进入编辑。
2. 打开「提醒我」，选择「提醒时间」，点右上角「保存」。
3. 手机第一次询问通知权限时，点「允许」。到点通知直接显示你写的任务内容；锁屏是否隐藏内容由手机的通知预览设置决定。
4. 完成或删除计划后，对应提醒会取消。每日重复计划只取消今天的提醒，明天仍会提醒。

没收到提醒时：计划本「设置 → 通知提醒」检查权限，再点「打开系统通知设置」，允许通知。也检查手机的专注模式、静音和通知摘要。已经过去的提醒时间不会补发。

每日提醒提前安排未来 30 天，总共保留最近 60 条；每次打开 App 或在桌面完成计划都会补充。设置会显示安排数量及不足，不是永远不打开也能无限续排。

## 像切水果一样完成计划

App 首页右上角点划切图标进入全屏页，横向划过任务卡片即可标记完成，看到刀光和碎片并获得震动反馈。普通上下滑动用于浏览，也可以点卡片上的完成按钮。

误划后点「撤销上一次完成」。这只是完成标记，不是删除任务。系统开启「减少动态效果」时，使用简短过渡。

## 以后更新

首次在计划本「设置 → 添加计划本更新源」中将源添加到 SideStore。

以后在计划本设置点「检查更新」，有新版时点「通过 SideStore 更新」；或直接打开 SideStore 点更新。保持 Wi-Fi 和 LocalDevVPN 已连接，按 SideStore 提示完成。

更新过程中可能需要你确认或重新登录，这是 iOS／SideStore 的要求。App 不会自己静默安装。每周续签仍需 SideStore 正常刷新；续签与软件版本更新是两件事。
