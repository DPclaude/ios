# 快捷互传 iPhone 原生版

SwiftUI / iOS 17+，单 App，无扩展、无网页容器、无第三方依赖。构建标识 `com.pandong.quicktransfer`，签名元数据名称 `QuickTransfer`，中文主屏幕名称“快捷互传”。

## 构建

在 macOS 安装 Xcode 和 XcodeGen 后运行：

```sh
bash scripts/ci-test.sh
bash scripts/build-ipa.sh
```

产物为 `build/QuickTransfer-unsigned.ipa`，需要通过 SideStore 等用户自己的签名安装流程重新签名。构建脚本不会读取 Apple 账户或设置付费签名能力。Simulator XCTest 不代替真机配对和本地网络权限验收。

## 使用

电脑端打开原生快捷互传并生成连接二维码。手机扫描后在电脑上核对同一六位核对码并确认。手机身份凭据和电脑证书指纹保存在 Keychain；再次扫描相同电脑只更新地址，不请求新设备。电脑更换证书需要主动断开旧连接再配对。

手机文件选择器先显示发送确认。发送会把文件复制到本地暂存，按 1 MiB 分块校验上传；重新打开后查询电脑的已持久化偏移继续。收到文件写入磁盘并流式校验 SHA-256，原子提交和持久化接收索引完成后才发回执。回执失败会重试，已入索引的文件不会重复下载。文字持久化到同一索引，不自动改剪贴板。

## 实际边界

- 当前连接仅支持同一局域网，发现使用 Bonjour 和已保存地址；每个 HTTPS 连接必须匹配配对二维码的 SHA-256 证书指纹。
- 请保持 App 在前台。后台或锁屏暂停后恢复发送分块；接收文件若尚未完成落盘，中断后会从头下载。没有无限后台接收承诺。
- 文件保存在 App 文稿区；“存入相册”是单独操作。共享菜单用于预览、保存到“文件”或交给其他应用。
- 一个当前电脑身份；更换电脑需要在设置断开。已有接收文件保留。手机名修改用于下一次配对，电脑端已有设备标签不自动修改。
- 照片通过系统选择器导入；视频和其他类型可通过“文件”选择。收发大文件需要足够暂存空间。
- 云端编译和单元测试通过后仍需要真机验证相机、本地网络权限、Bonjour、SideStore 签名和双向 1 GiB 传输。
